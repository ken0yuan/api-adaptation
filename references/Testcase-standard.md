# 测试执行结果

Step0.1 记录生成器在本次 NPU 环境的实际结果，Step1 核对报告并记录 GPU 参考验证。

| `execution` | 判定依据 |
|---|---|
| `not_run` | 尚未执行 |
| `pass` | 指定 NPU 环境中所需场景实际执行并全部通过 |
| `fail` | 实际断言失败或测试运行错误 |
| `skip` | 全部用例跳过 |
| `blocked` | 环境使测试无法启动 |
| `partial` | 部分场景通过，仍有跳过或未执行场景 |

已有文件和有效记录继续复用。报告记录实际命令、环境、被测源码版本和逐用例结果，保留原始日志。

本页的执行结果对应功能测试。内存、精度、确定性的补测需求按[四类测试约定](test-types.md)分别评估。
